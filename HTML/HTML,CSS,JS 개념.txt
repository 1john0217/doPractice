*(1) 첫 번째 의의 - html >> 구조가 정해져있는, 마크업언어.

[기존의 고정된 요소에서 보이거나 안보이게 하거나 하는 것일뿐이다. 색이 입히거나 갑자기 나타나거나 이런 것도 사실상 다 있는 요소에서 보이거나 안보이게 하는 것일뿐인 것이다.] - 이것의 한계를 이해해야한다.
